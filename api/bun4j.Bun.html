bun4j

Bun

The entry point of bun4j.

Bun.build(o -> o.entry("src/index.ts").outdir("dist").minify(true));
Bun.bundle(o -> o.entry("src/index.tsx").framework(Framework.REACT).dts(true));

autoManage(booleanenabled)void

booleanenabled

Whether to manage bun automatically.

Enables or disables the automatic install and update which runs before the first bun command in this JVM. The initial value can also be set with the bun4j.autoManage system property.

updateInterval()Duration

Duration

A duration.

Returns the minimum interval between two automatic update checks.

updateInterval(Durationinterval)void

Durationinterval

A duration.

Changes the minimum interval between two automatic update checks. The initial value can be set with the bun4j.updateInterval system property (for example P7D).

lastUpdateCheck()Instant

Instant

An instant, or null if no check has been recorded.

Returns when bun was checked for updates the last time.

installed()boolean

boolean

true if bun is installed locally or available on the PATH.

Returns whether a bun runtime is available.

installation()Installation

Installation

The installation, or null if bun is not available.

Returns the bun runtime which bun4j uses.

executable()Path

Path

An executable path.

Returns the path to the bun executable.

version()String

String

A version string.

Returns the version of the available bun, or an empty string if bun is not installed.
