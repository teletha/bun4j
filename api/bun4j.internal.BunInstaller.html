Bun4j

bun4j.internal

BunInstaller

Downloads, installs and updates the bun runtime.

defaultDirectory()Path

Path ~/.bun/bin.

Returns the default installation directory.

executableName()String

String bun.exe on Windows, otherwise bun.

Returns the name of the bun executable on the current platform.

resolve()Installation

Installation

The installation, or null if bun is not available.

Finds an installed bun. A managed installation in ~/.bun/bin takes precedence over the PATH.

resolve(Pathdirectory)Installation

Pathdirectory

A directory.
Installation

The installation, or null if no executable exists.

Finds a bun inside the specified directory.

install(InstallOptionoption)Installation

InstallOptionoption

The installation options.
Installation

The installed runtime.

Installs bun into the local directory.

update(UpdateOptionoption)Installation

UpdateOptionoption

The update options.
Installation

The updated runtime.

Updates the local bun. The official bun upgrade command is tried first, then a fresh download of the requested release.

version(Pathexecutable)String

Pathexecutable

A bun executable.
String

A version string, or an empty string if it cannot be detected.

Returns the version of an executable by running bun --version.
