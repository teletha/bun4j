Bun4j API Overview

This page provides a concise overview of the available APIs, including their purpose, key functionalities, and usage patterns. It serves as a starting point for developers to understand how to integrate and interact with the system effectively.

🛠️ Class

Bun The entry point of bun4j.
BundleOption The options of a library bundle.
LintOption The options of bun lint.
FormatOption The options of bun fmt.
BuildOption The options of bun build.
InstallOption The options of a local bun installation.
UpdateOption The options of a bun update.
BunInstaller Downloads, installs and updates the bun runtime.
CommandRunner Starts a bun process and pumps its output to the registered listeners.

🛠️ Enum

Framework Frontend frameworks supported by the library bundle presets.
SourceMap The sourcemap style of generated bundles.
ModuleFormat The module format of generated bundles.
Target The execution environment for a bundle.

🛠️ Record

Result The result of a bun command invocation.
Installation Describes the bun runtime which bun4j uses.
